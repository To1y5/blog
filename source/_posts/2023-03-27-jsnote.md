# DAY1

通过 id 操作 HTML 元素：

```js
document.getElementById()
```

操作元素属性：

```js
el.innerHTML
el.src
el.style
```

## JavaScript 显示方式

- `window.alert()` 弹窗
- `document.write()` 写入 HTML 输出
- `innerHTML` 写入 HTML 元素
- `console.log()` 控制台日志

`document.write()` 仅用于测试，调用后会删掉已有 HTML。

**JavaScript 对大小写敏感。**
