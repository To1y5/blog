题目：

![image-20230331214903142](image-20230331214903142.png)

代码：

```python
import datetime as dt
a = dt.date(1900,1,1)
def check(n):
    if n %2012==0  and n %3==0 and n %12==0 and str(n)[4:6]=='06':
        return True
    else:
        return False

x=1
while True:
    b = a + dt.timedelta(days=x)
    n = int("".join(str(b).split('-')))
    if check(n):
        print(n)
        break
    x+=1
```

日期相关的问题用 `datetime.date` 最方便。不用的话还得自己判断月份、天数、闰年二月。直接往上加天数，这些都不用管。

```python
def gcd(a, b):
    r = 1
    while (r != 0):
        r = a % b
        a = b
        b = r
    return a

def gbs(a,b):
    return a * b // gcd(a,b)

lst = [float('inf')]*(2021+1)
lst[1] = 0
for i in range(1, 2022):
  for j in range(i + 1, i + 22):
    if j > 2021:
      break
    lst[j] = min(lst[j], lst[i] + gbs(i, j))
print(lst[2021])
```

最短路径。
